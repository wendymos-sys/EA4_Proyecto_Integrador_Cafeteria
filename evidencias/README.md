
# Evidencias del proyecto integrador

Esta carpeta contiene las evidencias del desarrollo
del sistema de descuentos de la cafetería.

## Evidencias

1. Lógica de descuentos y programación funcional.
2. Conexión exitosa con SQLite mediante JDBC.
3. Interfaz gráfica Swing y pruebas de funcionamiento.
4. Diagrama de clases UML del sistema.

Estas evidencias respaldan la aplicación de los
conceptos de programación orientada a objetos,
herencia, polimorfismo, programación funcional,
persistencia de datos e interfaces gráficas.
